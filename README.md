# Utsav Chokshi — Robotics Portfolio

A plain HTML and CSS portfolio for GitHub Pages.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

Create a GitHub repository named `utsav-chokshi.github.io`, connect this folder to it, and enable GitHub Pages from the repository's `main` branch.

## Site files

- `index.html` — portfolio content
- `styles.css` — responsive visual styling
